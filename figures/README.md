# Figures

All figures are built from the CSVs in `data/` and `appendix/` (version 2, all stages on Claude Opus 5.5). The 2026 vintage is year-to-date (benchmark results to 28 September 2026).

| File | What it shows |
|---|---|
| [fig_ability_year_heatmap.png](fig_ability_year_heatmap.png) | Exposure of all 52 abilities by year, 2020 to 2026; hatched cells have no benchmark. |
| [fig_growth_extremes.png](fig_growth_extremes.png) | The ten occupations whose exposure grew most and least from 2020 to 2026, teachers bundled. |
| [fig_scatter_bwi_aei.png](fig_scatter_bwi_aei.png) | BWI 2024 exposure against AI usage in early 2025 for the 339 occupations with recorded usage; the 405 without are the rug below the axis. |
| [fig_quadrants_2024_2025.png](fig_quadrants_2024_2025.png) | The same pairing as quadrants, with 36 occupations labelled. |
| [fig_baioe_aei_grid.png](fig_baioe_aei_grid.png) | Counts of occupations by BWI 2024 decile and usage decile; the bottom row is the 405 with no recorded usage. |
| [fig_corr_by_vintage.png](fig_corr_by_vintage.png) | Rank correlation of each BWI vintage with usage, for both usage waves. |
| [fig_horserace_cv.png](fig_horserace_cv.png) | Out-of-sample fit when predicting 2026 usage from past usage, BWI, or both. |
| [fig_anatomy_jobs.png](fig_anatomy_jobs.png) | The five abilities contributing most to the score of nine example occupations. |
| [fig_clustered_heatmap.png](fig_clustered_heatmap.png) | Which abilities drive the scores of the 40 most exposed occupations. |
