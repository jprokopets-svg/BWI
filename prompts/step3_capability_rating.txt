=== HARD PRECONDITIONS -- CHECK FIRST, BEFORE ANYTHING ELSE ===
If ANY of the following is true, do NOT produce a capability score. Return the JSON with
"human_comparative_score_0_10": null, "ungradable": true, and a reason. Do not infer a
score from the benchmark name or description alone:

    A. NO SCORE DATA. ai_score is empty, null, absent, or "N/A" for this year. A benchmark
       with no measured AI performance cannot be rated. Do not substitute a guess based on
       the task description. (This is a fabrication guard -- an unmeasured benchmark stays
       unmeasured.)
    B. SCORE IS A RANK OR PLACEMENT. If ai_score represents tournament rank, placement,
       "1st"/"won", medal, or leaderboard position rather than a performance metric
       (accuracy, success rate, reward, WER, BLEU, MOS, F1, etc.), it is NOT a capability
       measure. Return null + ungradable, reason "score is rank/placement, not performance."
    C. METRIC INCOHERENT ACROSS THE OBSERVATION. If score_metric is missing, or the value
       is impossible for the stated metric (e.g. a "success rate" of 3789, an "accuracy"
       of 661), flag it: set "unit_warning": true and lower confidence accordingly. Do not

Only if A, B, and C all pass, proceed to scoring.

=== UNIT SANITY CHECK (do this before scoring) ===
Before rating, confirm ai_score is in the units score_metric implies. Common failure: a
score recalled in the wrong scale (0-1 reported as 0-100, or vice versa), or a different
aggregation than the metric name suggests. If the value looks off-scale for the metric
(e.g. score_metric says "accuracy (%)" but value is 0.87, or says "success rate" but
value exceeds 100), state your interpretation in ai_score_interpreted and reflect the
uncertainty in confidence. Do not silently assume the number is correct.

Cross-check: compare score_metric (the static benchmark-level metric description) against
score_source_note (the per-year source note describing what was actually measured). If
they disagree on metric, units, or aggregation method, flag the inconsistency in
ai_score_interpreted and lower confidence.

Important principle: Do NOT mechanically map percent correct to human percentile. Some
benchmarks are easy for humans; others are so hard that a small nonzero score implies
elite ability (e.g. FrontierMath). Account for benchmark difficulty explicitly.

Evidence hierarchy:
1. Direct human comparison available -> use published human/expert/crowdworker baselines
   as primary evidence.
2. Score + known difficulty -> infer human comparison from task nature, target population,
   historical saturation.
3. Score only -> estimate cautiously from description, domain, metric, and known
   difficulty class of similar benchmarks.

Provenance adjustment: If notes_or_sources indicates the score came from model recall
(sonnet_v2) with no external citation, lower your confidence -- recall is reliable for
major benchmarks but unverifiable for niche ones. External sources (epoch_csv, cited
web_search) are not subject to a confidence gap.

Human comparison reference groups: General adult / Relevant educated-workforce / Expert.
Choose the most appropriate for the benchmark.

Main score -- human_comparative_score_0_10: Answers "how capable is the AI on this
observation vs humans who'd plausibly perform the corresponding work task?" THIS IS THE
ONLY FIELD CONSUMED DOWNSTREAM (Step 5).

Rubric:
0 = No meaningful competence / near random / invalid.
1 = Far below ordinary human; isolated capability, fails almost all real uses.
2 = Very weak novice; easiest cases only.
3 = Low human level; weak novice / below-average adult.
4 = Partial useful competence; below median relevant human but assists on simple cases.
5 = ~Median relevant-human performance.
6 = Above-average human; better than most, not clearly professional.
7 = Strong professional / advanced-student level.
8 = Expert level; strong professionals, graduate specialists.
9 = Elite human; top experts, competition-level, upper tail.
10 = Superhuman or saturated elite; exceeds nearly all humans, or approaches ceiling on
     an expert-designed task.

confidence_0_1:
0.90-1.00 = direct high-quality human baseline + clear score.
0.75-0.89 = good metadata, plausible comparison, imperfect.
0.55-0.74 = meaningful inference required (and the cap for sonnet_v2-only scores).
0.35-0.54 = sparse/indirect/uncertain difficulty.
0.00-0.34 = highly speculative; missing/uninterpretable score (and the cap when
            unit_warning is true).
